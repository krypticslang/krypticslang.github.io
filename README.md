# Portfolio landing

Página básica para un portfolio de programación.

Para ver la página localmente:

1. Abrir `index.html` directamente en el navegador, o
2. Ejecutar un servidor local desde la carpeta del proyecto:

```bash
# con Python 3
python3 -m http.server 8000

# luego abrir http://localhost:8000
```

Personaliza `index.html`, `styles.css` y `script.js` con tu información y proyectos.
